 🌾 Crop Nutrition Explorer

A web app to search and explore nutritional data of crops using the USDA FoodData Central API.

API Used
USDA FoodData Central — https://api.nal.usda.gov/fdc/v1/

Features
- Search crops by name
- Filter by category (Cereal, Vegetable, Fruit, Legume)
- Sort by protein or calories
- Add crops to favourites (saved in localStorage)
- Dark / Light mode toggle
- Responsive on mobile and desktop

Technologies
HTML, CSS, JavaScript
